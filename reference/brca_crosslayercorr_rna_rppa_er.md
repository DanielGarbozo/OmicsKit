# TCGA-BRCA RNA-RPPA cross-layer correlations

A data frame with RNA-RPPA cross-layer correlation results across shared
samples and genes.

## Usage

``` r
brca_crosslayercorr_rna_rppa_er
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
