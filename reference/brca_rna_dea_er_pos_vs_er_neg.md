# TCGA-BRCA RNA-seq DEA: ER-positive versus ER-negative

A data frame of RNA-seq differential-expression results comparing
ER-positive and ER-negative primary tumor samples.

## Usage

``` r
brca_rna_dea_er_pos_vs_er_neg
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
