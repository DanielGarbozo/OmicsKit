# TCGA-BRCA clinical PFI level summary

A data frame summarizing clinical predictor levels for progression-free
interval modeling.

## Usage

``` r
brca_clinical_level_summary_pfi
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
