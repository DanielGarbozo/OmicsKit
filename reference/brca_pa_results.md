# TCGA-BRCA pathway-analysis results

A pathway-analysis result table used in OmicsKit pathway plotting, gene
retrieval, and annotation examples.

## Usage

``` r
brca_pa_results
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
