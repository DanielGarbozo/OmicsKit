# Merged TCGA-BRCA pathway-analysis results

A compact pathway-analysis table combining all BRCA comparisons and
collections in an OmicsKit-compatible schema.

## Usage

``` r
brca_pa_merged
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
