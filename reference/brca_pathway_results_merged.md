# Merged TCGA-BRCA pathway results

A merged pathway-analysis result table used as an example object for
OmicsKit pathway workflows.

## Usage

``` r
brca_pathway_results_merged
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
