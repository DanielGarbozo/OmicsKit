# TCGA-BRCA MSigDB gene-set list by collection

A named list separating BRCA gene sets by MSigDB collection, including
Hallmark and GO Biological Process.

## Usage

``` r
brca_geneset_list_by_collection
```

## Format

A named list.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
