# TCGA-BRCA pathway similarity object

A pathway similarity object created from real GMT memberships for BRCA
pathway clustering examples.

## Usage

``` r
brca_pa_similarity
```

## Format

A package data object.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
