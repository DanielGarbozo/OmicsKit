# TCGA-BRCA RNA metadata for tumor-normal comparison

A data frame with sample annotations aligned to the tumor-normal RNA-seq
expression matrix.

## Usage

``` r
brca_rna_metadata_tumor_normal
```

## Format

A numeric matrix with features in rows and samples in columns.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
