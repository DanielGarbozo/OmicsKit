# TCGA-BRCA GSEAPreranked Hallmark: tumor versus normal

A standardized GSEAPreranked Hallmark result table for the tumor versus
normal comparison.

## Usage

``` r
brca_gsea_tumor_vs_normal_hallmark
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
