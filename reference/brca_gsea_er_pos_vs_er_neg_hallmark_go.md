# TCGA-BRCA PA object: ER-positive versus ER-negative

A compact pathway-analysis table combining Hallmark and GO BP results
for ER-positive versus ER-negative.

## Usage

``` r
brca_gsea_er_pos_vs_er_neg_hallmark_go
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
