# Merged TCGA-BRCA GSEAPreranked results

A merged standardized GSEAPreranked result table across Hallmark and GO
BP collections and both BRCA comparisons.

## Usage

``` r
brca_gsea_all_comparisons_hallmark_go_bp
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
