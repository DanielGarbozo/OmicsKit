# TCGA-BRCA clinical modeling log

A data frame recording retained and dropped variables and diagnostics
from the clinical modeling workflow.

## Usage

``` r
brca_clinical_modeling_log
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
