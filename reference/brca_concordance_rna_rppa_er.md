# TCGA-BRCA RNA-RPPA concordance results

A data frame with cross-layer concordance statistics between RNA-seq and
RPPA for the ER comparison.

## Usage

``` r
brca_concordance_rna_rppa_er
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
