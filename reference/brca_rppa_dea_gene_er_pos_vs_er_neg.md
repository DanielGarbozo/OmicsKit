# TCGA-BRCA RPPA gene-level DEA

A data frame of RPPA gene-level differential-abundance results comparing
ER-positive and ER-negative samples.

## Usage

``` r
brca_rppa_dea_gene_er_pos_vs_er_neg
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
