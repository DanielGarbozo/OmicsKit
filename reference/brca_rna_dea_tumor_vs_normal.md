# TCGA-BRCA RNA-seq DEA: tumor versus normal

A data frame of RNA-seq differential-expression results comparing tumor
and normal samples.

## Usage

``` r
brca_rna_dea_tumor_vs_normal
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
