# TCGA-BRCA omics-layer figure provenance

A list describing the real pre-rendered multi-omics genome-track and
circos figures for sample TCGA-A1-A0SH-01.

## Usage

``` r
brca_omics_layer_tracks
```

## Format

A named list.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
