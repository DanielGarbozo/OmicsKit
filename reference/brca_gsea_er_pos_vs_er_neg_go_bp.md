# TCGA-BRCA GSEAPreranked GO BP: ER-positive versus ER-negative

A standardized GSEAPreranked GO Biological Process result table for the
ER-positive versus ER-negative comparison.

## Usage

``` r
brca_gsea_er_pos_vs_er_neg_go_bp
```

## Format

A data frame.

## Source

TCGA-BRCA example data processed by OmicsKit scripts under
`data-raw/brca/`. External pathway results were generated by the
GSEA-Pipeline preranked workflow and imported into OmicsKit.
